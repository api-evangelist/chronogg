Chronogg, now operating as Nexus, provides a Support-a-Creator platform that enables game developers and publishers to reward and pay content creators for promoting their games. The service offers creator code systems, performance‑based payouts, and tools for managing creator programs, aiming to boost engagement, retention, and revenue for live‑service games.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Chronogg: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
